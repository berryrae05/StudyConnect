# Frontend Setup Guide
This guide hepls set aup and run the React frontend for the Study Connect project.

---

## 1. Prerequisites

### Install Node.js
Download Node.js:

```text
https://nodejs.org
```

Check installations:

```bash
node -v

npm -v 
```

## 2.Frontend Project Setup

The React frontend has already been created using:

```bash
create-react-app
```

You do NOT need to create the project again,

Move into the frontend folder:

```bash
cd frontend
#Move into the fronend folder
```

## 3.Install Dependencies
Install all required frontend dependencies

```bash
npm install
# Installs dependencies listed in package.json
# Recreates node_modules automatically
```
Important:

```text
Do NOT upload node_modules to GitHub
```
## 4. Run the Frontend

Start React server:

```bash
npm start
```
