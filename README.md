# StudyConnect

## Project Description
Study Connect is a web-based platform designed to help university students organise and find study groups on campus. The platform addresses a common student pain point, the difficulty of finding peers to study with for a specific module, at a convenient time, in a suitable location. It providesa a structured, searchable space for study group coordination.
Students register using their institution email address, ensuring the platform remains exclusive to the university community.

Once registered, a student can either:
- Create study groups by specifying:
    - Module
    - Date & time
    - On-campus venue
    - Maximum number participants
    - Gender preference
- Search for existing study groups by module and filter by date to find a session that fits their schedule.
  
Study Connect is being built for a single institution initially, with the architecture designed to support adoption by additional universities over time.
